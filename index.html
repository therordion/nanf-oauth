NANF — персональное приложение доступа

Это приложение загружает видео на YouTube-канал владельца и читает статистику его собственных видео через официальный YouTube Data API v3.

Приложение использует один аккаунт — аккаунт владельца канала. Доступ выдан самим владельцем, в любой момент он может отозвать его в настройках Google (myaccount.google.com/permissions).

Подробности: политика конфиденциальности.

Страница существует потому, что Google требует домашнюю страницу и политику конфиденциальности для публикации OAuth-приложения.
